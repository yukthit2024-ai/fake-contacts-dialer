**Prompt:**
When a fake call is going on, either incoming or outgoing, if a real phone call comes, mute the ringing volume.

---

### Implementation Details

**1. Added `READ_PHONE_STATE` Permission**
- Updated `AndroidManifest.xml` to declare the `android.permission.READ_PHONE_STATE` permission.
- Updated `MainActivity.java` to request this permission at runtime so the app can detect real incoming phone calls.

**2. Created `RealCallVolumeHelper.java`**
- Added a new helper class that registers a `BroadcastReceiver` for `TelephonyManager.ACTION_PHONE_STATE_CHANGED`. 
- When the phone state changes to `RINGING` or `OFFHOOK` (indicating a real phone call is active), it mutes the associated `MediaPlayer` and the system ringtone to 0 (`0.0f`).
- When the phone returns to `IDLE`, it restores the volume back to 100% (`1.0f`).

**3. Updated `AudioPlayerHelper.java`**
- Added a `setVolume(float volume)` method that interfaces with the underlying `MediaPlayer` to scale its volume dynamically during an active fake call.

**4. Integrated Volume Management in Fake Call Activities**
- Updated `IncomingCallActivity.java`, `DialingActivity.java`, and `InCallActivity.java`.
- An instance of `RealCallVolumeHelper` is created and registered when each activity is launched, bound to the respective audio playback component.
- The helper is correctly unregistered during the `onDestroy` lifecycle events of these activities.
